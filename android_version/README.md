# Pipe Counter Pro - Mobile Android Version

This folder contains the complete Flutter mobile application codebase for Android.

### Key Improvements:
* **Horizontal Swipeable Toolbar:** The top tool ribbon (`Pan`, `Crop ROI`, `Add`, `Delete`, `Toggle`, `# ON`, `Undo`) is horizontally scrollable and swipeable so that no buttons are cut off on narrow smartphone displays.
* **Centered Floating Action Controls:** Radius selection and crop controls adapt smoothly to screen width.
* **Calibrated Radius Bounds:** Default detection range adjusted (8px - 140px) to match realistic mobile camera pipe bundle captures.

### How to Build APK:
* Double-click `Build_APK.bat` to compile the release APK locally.
* Output: `PipeCounterPro_Android.apk`
